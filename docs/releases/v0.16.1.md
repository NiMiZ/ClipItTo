## ClipItTo 0.16.1: Settings fixes

**Bug fixes (3), and a clearer installer**
- **Settings scroll, and the window fits the screen.** The Passwords page (with the Panic key and Auto-forget) was taller than a small screen, and
  the window had no scrolling, so its last settings were cut off. Every page now scrolls, and the window is never taller than your screen.
- **Opening Settings no longer shows the keyring note.** Settings read the sync key from the keyring even with sync off, and ClipItTo then
  explained the keyring, on Windows too, where the Credential Manager never shows a window. The key is now read only once sync is on, and
  the note appears only where the keyring can really ask you for something.
- **The rules editors open in their own windows.** Password rules, Auto-forget rules and the paste-keys programs each have an *Edit rules…*
  button and a one-line summary on the page (red when a rule is not valid), so Settings no longer grows with every rule.

**Installer (Windows)**
- The installer now says on its first and "ready" pages that it closes a running ClipItTo for you (it always did), so there is no need to quit it first.
