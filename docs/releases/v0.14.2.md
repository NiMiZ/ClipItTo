## ClipItTo 0.14.2: password rules, a diagnostic log, and fixes

**New (3)**
- **Your own password rules.** Settings › Passwords › *Password rules*: up to 5 rules, each a length (6 to 256 characters),
  minimum counts of lower case, upper case, digits and symbols, and *digits at the end*. A single-line copy that fits a rule is kept as
  a password copy (for example 6 lower case letters and 2 digits at the end). A *Try it* box tests a sample; it is never saved or logged.
- **A diagnostic log for troubleshooting.** Settings › Passwords has a checkbox, *Write a diagnostic log*, and `clipitto --verbose`
  does the same for one run. It writes a private, rotating `debug.log` in the data folder (never the contents of a copy).
  `clipitto --status` also says why password copies are or are not being kept.
- **Ubuntu 26.04 `.deb`.** The release now has a separate `.deb` for Ubuntu 26.04 next to the one for 24.04.

**Improvements (2)**
- **The Number menu is grouped by base:** the *Read as hex* items together and the *Read as decimal* items together.
- **A single copied file path is shown in full** in the list, not only its file name.

**Bug fixes (1)**
- **A translation that takes too long is cancelled** (`translate_timeout`, 5 seconds by default, 1 to 10), so it can no longer leave the
  app stuck.

(Earlier in 0.14.1, not yet released: the popup opens from the top of the list, and the password name box comes to the front.)
