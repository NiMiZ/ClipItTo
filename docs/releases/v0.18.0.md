## ClipItTo 0.18.0: paste keys for every desktop, finer password ignore rules, and a Support button

**New (3)**
- **Global paste key.** Settings › General › *Paste keys* now also offers **Ctrl+Shift+V**, used for every program that has no rule of its
  own. This is for desktops that cannot tell which program is in front (KDE and wlroots on Wayland), where per-program rules never match.
  Per-program rules and the built-in terminal list still win where the program is known. macOS always uses Cmd+V.
- **Switch the built-in "not a password" rules off one by one.** Settings › Passwords › *Password ignore* › *Edit rules…* now has a checkbox for
  each built-in kind (environment variable, file path, registry key, host and port, dotted name, URL, email address). Auto-forget now sits right
  under Password ignore.
- **Support ClipItTo.** Settings › General has a *Support ClipItTo…* button that opens a donation page in your browser. It does nothing until you
  click it; ClipItTo itself still makes no connection. The program stays free (GPL-3.0).

**Also**
- The Windows program files and the installer now carry a product name, version and publisher in their file properties (a step toward signing
  the Windows files, so Windows can show a publisher instead of "Unknown publisher").
