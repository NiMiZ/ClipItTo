## ClipItTo 0.10.0: 2 bug fixes, 2 improvements

**Bug fixes (2)**
- **Ctrl+T and the translation hints no longer look like an error.** They used the warning box (yellow sign, system beep). They now appear in a
  quiet window, and a translation has a **Paste** button.
- **A translation that gets stuck no longer leaves the popup stuck** (reported on Windows for a Hebrew word; not reproduced on Linux).
  The popup stops waiting after 30 seconds and says so, the engine uses one thread, a second translation no longer waits behind a stuck
  one, and `translation/translation.log` in the data folder records times and sizes (never the text) to find the cause.

**Improvements (2)**
- **Choose and order the Shift+Enter menu.** A new *Paste as* tab in Settings lists the items for text and for pictures: tick, move up and
  down (or drag), and reset to the default. The right-click *Paste as* submenu follows the same list.
- **Moving a copy into the Passwords group makes it a password copy** in one step (it needs a master password; without one the move is
  refused). *Mark as password* stays for copies that should keep their place.
