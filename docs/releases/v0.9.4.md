## ClipItTo 0.9.4: 4 bug fixes, 3 improvements

This is the first release since 0.9.1. The versions 0.9.2 and 0.9.3 were tagged but never published (their builds ran into
GitHub's storage limits), so everything since 0.9.1 is here.

**Bug fixes (4)**
- #58 **Ctrl+E adds or edits a note straight from the search box**, where the popup starts.
- #59 **A single word is no longer translated twice** ("hello" gave "שלום שלום"): for one to three words the first
  candidate that doesn't repeat itself is taken.
- #61 **Searching a word with several matches** selects the newest unsaved match when the start focus is "Unsaved history".
- #62 **Groups show on the first open after login** (they were scrolled out of sight until you pressed Up).

**Improvements (3)**
- #70 **Ctrl+E edits the copy itself, not only its note**: a Note box and a Text box. Saving the text keeps the note, group,
  star, pin and place in Recent; when the edited copy is the newest, the system clipboard is updated too and a notification says so.
- #60 **Ctrl+T shows a translation without pasting it**, and the model's output for a short text is capped by the text's length.
- #74 **F2 renames**: the selected group (folder) or, on a copy, its note.

**Behind the scenes**
- The CI builds macOS on `macos-15` (GitHub is retiring `macos-14`), uploads build files only for release tags and keeps them
  3 days, and skips the checks that need a public repository while the repository is private.
