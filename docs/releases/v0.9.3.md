## ClipItTo 0.9.3: 0 bug fixes, 1 improvement

**Improvement (1)**
- #70 **Ctrl+E edits the copy itself, not only its note.** One dialog with two boxes: the Note, and the Text (multi-line). A picture or a password copy has only the Note. Saving the text keeps the note, group, star, pin and the place in Recent. It refuses empty text, text over the size limit and text that is already another copy. When the edited copy is the newest, the system clipboard is updated as well and a notification says so.

**Also in this release**
- The 0.9.2 fixes (4 bug fixes, 1 improvement; see the notes of 0.9.2), if 0.9.2 was not published on its own.
- CI: build files are uploaded only for release tags, so pull-request runs no longer use up the free storage quota.
