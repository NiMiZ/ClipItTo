## ClipItTo 0.14.1: 2 bug fixes

**Bug fixes (2)**
- **The popup opens from the top of the list.** With Pinned copies above Recent, the popup could open scrolled down so that only Recent
  showed; Pinned and the Groups row are visible again.
- **The password name box comes to the front.** The box that asks for a name after a password was copied (or marked) now stays on top
  and takes the keyboard focus, so you can type the name; it was able to open behind other windows and grab focus from all of them.
  It also closes itself after a minute (the copy keeps its default note), so it can never hold the app waiting.
