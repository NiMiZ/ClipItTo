## ClipItTo 0.19.0: Check for updates, regex search, snapshots, file thumbnails, similar copies and a search help

**Privacy note first.** Until now ClipItTo made no network connection except the optional *Receive from phone* window (local network only). 0.19.0 adds one more, and only when **you** ask for it: **Check for updates**. It sends the app's version and your platform (windows, linux or macos) over HTTPS to cohenzco.com, and nothing else; the site necessarily sees your IP address. It never downloads or installs anything: if there is a newer version it opens the download page in your browser. The automatic daily check is **off by default**.

**New (6)**
- **Check for updates.** Settings › General › *Check for updates…* (and a tray item on Windows and macOS). Optional daily check in Settings (off by default; at most once a day; quiet unless there is an update; not repeated for a version you said *Later* to).
- **Regex search.** Type `re:<pattern>` in the search box (for example `re:^https?://.*\.pdf$`; `re:"a b"` with spaces; case-insensitive, `(?-i)` to switch that off). A bad or slow pattern never freezes the popup: a 0.3 s limit, and the results found so far stay.
- **Search help and `pw:`.** Typing `/?` in the search box lists everything it understands. Password search now also starts with `pw:` (as well as `p[]` or your own keyword); what you type after it is hidden.
- **Snapshots.** Save a group or a copy as a named snapshot (right-click) and restore it later, even after the history was pruned or cleared. Passwords and pictures are never included; the panic key and *Wipe everything now* also remove snapshots.
- **Similar copies.** Right-click a text copy › *Show similar copies* lists copies that match after ignoring case and spacing (or are almost the same), with a *Keep this one, delete the others* button that asks first and never touches pinned, starred, grouped or noted copies.
- **Thumbnails for copied picture files**, and files copied in Nautilus on GNOME are now recorded as file lists (log out and in after updating so GNOME loads the new extension).

**Also**
- The Windows files carry a product name and version; a Microsoft Store package (MSIX) can be built (not published yet).
- The README, install page and release pages say plainly that the Windows files are not code-signed yet; check them against `SHA256SUMS`.
- After a release, the release job asks cohenzco.com to read the new version at once.
