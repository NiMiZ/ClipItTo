## ClipItTo 0.16.0: paste once, auto-forget, and a shorter password clipboard

**New (2)**
- **Paste once.** Mark a copy *Paste once* (right-click or Shift+Enter menu, a toggle) and it is removed from the history right after you
  paste it from ClipItTo, and the clipboard is cleared 2 seconds later if it still holds that text (*Settings*: `paste_once_clear_seconds`,
  0 turns it off). **Ctrl+Shift+Enter** pastes the selected copy and forgets it in one go. A small *once* tag shows on the row.
  - A password copy is pasted first, then ClipItTo asks *Delete this password copy?* every time; *No* keeps it.
  - Pinned and starred copies are never deleted, only un-marked. Pictures and grouped copies are deleted.
  - If the paste keys were not sent, nothing is deleted. After a deletion, **Undo** (the button, or Ctrl+Shift+Z) restores the copy for 10 seconds.
  - Paste once copies are left out of backups.
- **Auto-forget rules.** Settings › Passwords › *Auto-forget*: up to 8 rules that remove copies by themselves, after N days
  (optionally only text or only pictures), or after N minutes when the text contains a string you give or looks like a token, key or card
  number. Pinned, starred, grouped and password copies are never removed. Rules run at start, once a minute and when the popup opens;
  removals are silent. None are set by default.

**Changed (1)**
- **The clipboard is cleared 2 seconds after pasting a password** (it was 30). *Settings › Passwords*; 0 turns it off, up to 60 seconds. It
  only clears when the clipboard still holds the password, so a newer copy of yours is never wiped.

**Behind the scenes**
- A test-suite of about 340 new automated checks for passwords, grouping, copying from many apps, the GUI, translation and stalls
  (the performance tests found and fixed the stalls listed under 0.15.0).
